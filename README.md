# Система учета доменных имен

Консольное приложение для учета доменных имён, их владельцев
и организаций, а также контроля сроков регистрации.

## Назначение
Приложение предназначено для учёта зарегистрированных доменных имён,
закреплённых за организациями и ответственными пользователями,
и для контроля сроков действия регистрации доменов.

## Целевая аудитория
Администраторы доменов, IT-специалисты и небольшие организации,
которым необходимо централизованно отслеживать принадлежность
и сроки действия своих доменных имён.

## Предметная область
Пользователь может владеть несколькими доменами. Каждый домен
закреплён за организацией и имеет владельца (пользователя) и срок
действия регистрации. Удалённый из активного использования домен не
удаляется из истории — он помечается неактивным.

## Основные сущности
### Domain — домен
Объект `Domain` представляет доменное имя.

Основные атрибуты:
- `id` — уникальный идентификатор домена;
- `name` — название домена;
- `organization` — организация, за которой закреплён домен;
- `registration_end` — срок действия регистрации;
- `owner` — объект `User`, владелец домена;
- `is_removed` — признак исключения из активного использования.

Основные методы:
- `is_active()` — проверка активности домена на текущую дату;
- `renew()` — продление срока регистрации;
- `remove()` — мягкое удаление (история сохраняется);
- `__str__()` — строковое представление домена.

### User — пользователь
Объект `User` представляет владельца доменов.

Основные атрибуты:
- `id` — уникальный идентификатор пользователя;
- `name` — имя пользователя;
- `email` — адрес электронной почты.

Основные методы:
- `__str__()` — строковое представление пользователя;
- `from_data()` — создание пользователя из словаря данных.

## Взаимодействие объектов
Домен хранит ссылку на объект `User` в атрибуте `owner`, а не только
его идентификатор:

```
domain.owner.name
domain.owner.email
```

При сохранении в JSON связь заменяется идентификатором `owner_id`;
при загрузке идентификатор используется для поиска существующего
объекта `User` и восстановления ссылки.

## Возможности
- просмотр и поиск доменов (по названию и организации);
- просмотр пользователей;
- добавление пользователя;
- добавление домена с привязкой к владельцу;
- продление срока регистрации;
- удаление домена (без потери истории);
- статистика по реестру.

### Назначение модулей
- `main.py` — точка запуска, меню приложения;
- `models/domains.py` — класс `Domain` и функции работы с коллекцией доменов;
- `models/users.py` — класс `User` и функции работы с коллекцией пользователей;
- `storage.py` — загрузка и сохранение данных, преобразование JSON ↔ объекты;
- `utils.py` — вспомогательные функции безопасного ввода;
- `tests/` — автоматизированные тесты.

## Формат хранения данных
- `data/users.json` — список словарей с полями `id`, `name`, `email`;
- `data/domains.json` — список словарей с полями `id`, `name`, `organization`,
  `registration_end` (`ГГГГ-ММ-ДД`), `owner_id`, `is_removed`.

## Требования
- Python 3.11+;
- pytest;
- flake8;
- black (форматирование кода).

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск программы
```
python main.py
```

## Запуск тестов
```
pytest -v
```
Тесты проверяют: создание и атрибуты объектов `Domain` и `User`, связь
домена с владельцем, продление и удаление домена, поиск по коллекциям.

## Проверка и форматирование кода
```
flake8 .
black .
```
`black` автоматически приводит код к единому стилю, `flake8` проверяет
соответствие PEP 8 и находит неиспользуемые импорты/переменные.
