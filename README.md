# Система учета доменных имен

## Назначение
Приложение предназначено для учёта зарегистрированных доменных имён, закреплённых за организациями и ответственными пользователями, а также для контроля сроков действия регистрации доменов.

## Целевая аудитория
Администраторы доменов, IT-специалисты и небольшие организации, которым необходимо централизованно отслеживать принадлежность и сроки действия своих доменных имён.

## Предметная область
Предметная область охватывает процесс регистрации и продления доменных имён: каждый домен закрепляется за организацией и пользователем-ответственным, для домена фиксируется дата окончания срока регистрации.

## Основные сущности
- Домен
- Пользователь
- Организация
- Срок действия регистрации

## Основные функции
- Добавление нового домена с указанием владельца, организации и срока регистрации
- Проверка статуса домена (активен / истёк) на текущую дату
- Расчёт количества дней, оставшихся до окончания срока регистрации домена

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
