# Система учета доменных имен

Консольное приложение для учета доменных имён, их владельцев
и организаций, а также контроля сроков регистрации.

## Назначение
Приложение предназначено для учёта зарегистрированных доменных имён,
закреплённых за организациями и ответственными пользователями,
и для контроля сроков действия регистрации доменов.

## Целевая аудитория
Администраторы доменов, IT-специалисты и небольшие организации,
которым необходимо централизованно отслеживать принадлежность
и сроки действия своих доменных имён.

## Предметная область
Каждый домен закрепляется за организацией и пользователем-ответственным;
для домена фиксируется дата окончания срока регистрации.

## Основные сущности
- Домен
- Пользователь (владелец)
- Организация
- Срок действия регистрации

## Возможности
- просмотр и поиск доменов (по названию и организации);
- проверка статуса домена (активен / истёк);
- добавление новых доменов;
- продление срока регистрации;
- удаление домена из реестра;
- статистика по реестру (количество активных/истёкших, среднее число
  дней до окончания срока).

## Структура проекта
- `main.py` — точка запуска, меню приложения;
- `domains.py` — работа с доменами (добавление, поиск, фильтрация);
- `registrations.py` — работа со сроком регистрации (статус, продление,
  удаление, сортировка, статистика);
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файл с данными реестра;
- `tests/` — автоматизированные тесты.

## Формат хранения данных
Домены хранятся в `data/domains.json` в виде списка словарей с полями
`id`, `name`, `owner`, `organization`, `registration_end` (дата в формате
`ГГГГ-ММ-ДД`).
